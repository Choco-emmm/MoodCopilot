# Changelog

## 2026-10-30 — 配额、日记任务恢复与引用隔离修正

- 周报和月报的用户生成入口在启动异步任务前检查 REPORT 配额。
- 日记分析覆盖附件输入版本，每次用户提交使用独立操作标识，避免复用已结束任务后停在分析中。
- 过期投递租约可由新进程恢复，条件更新保护仍在执行的任务。
- 小程序私人引用绑定账号，在退出、换号、账号合并和认证失败时清理，发送前再次检查归属。

## 2026-10-23 — 聊天记忆审批与隐私保护

- 聊天可提出记忆修改，展示前后差异，由用户编辑、确认后保存；拒绝与不可审批通道分别反馈。
- 统一记忆类型、证据、长度及敏感资料校验，自动抽取不能覆盖已有正式记忆；新增事务回执保护重试与恢复。
- 模型请求仅发送凭证脱敏副本，保留原始日记、聊天、引用及 JSON 后的正常请求文字。
- 修复审批恢复、取消后继续执行、附件重试、候选旧决定和记忆连续编辑的问题，调整聊天与记忆编辑框的尺寸处理。
- 后端新增兼容回执表迁移；发布使用固定提交镜像，保留服务器配置和数据卷。

## v1.3.0 — 图片 + 音乐 + AI 硬核升级 ✨

- **图片上传**：接入视觉大模型（qwen3-vl-flash），AI 能理解图片内容并纳入分析和记忆
- **音乐分享**：粘贴音乐链接自动解析歌名/歌手/歌词，AI 将音乐信息纳入分析和记忆
- **编辑体验**：编辑旧日记采用写日记页面，废除旧编辑口
- **Bug 修复**：编辑旧日记不再污染新草稿；优化配额表文字展示；系统构建和传输更稳定流畅
