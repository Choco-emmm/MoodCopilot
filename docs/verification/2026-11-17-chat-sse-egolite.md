# 聊天 SSE：egolite 本地实测

2026-11-17，按用户指定使用 egolite 操作真实网页，连接本次工作区启动的本地后端。没有部署到生产环境，也没有模拟模型回复或拦截业务 API 返回值。

## 环境与方法

- 后端：`npm.cmd run app:start` 启动的 dev 实例，`http://127.0.0.1:18080`，使用本次工作区 Java 代码。
- 前端：Vite preview，`http://localhost:5173`，`/api` 代理到本地 `18080`；使用浏览器已有的本应用本地登录会话。
- 浏览器：egolite，任务空间 1；测试会话 ID 为 44，标题“流式链路测试”。
- 观测：浏览器内包装 `fetch`，仅记录 SSE 的路径、序号、类型、长度与到达时间；没有导出登录凭据或日记正文。
- 故障注入：一次主动中止 SSE 的网络请求，另一次在收到文本分片后刷新页面。未调用取消任务接口。

## 发现的环境问题

`app:start` 的默认入口 `http://127.0.0.1:4173` 可以读取页面和 GET 接口，但创建会话的 POST 返回 `403 Invalid CORS request`。后端默认允许 `http://localhost:5173`，因此本次另起 5173 预览入口完成验证，没有放宽 CORS 或修改业务代码。

## 验证范围与保留状态

- 本次是单实例本地真人界面链路测试；跨实例通知、Redis 连接故障和无空闲轮询另由后端自动化测试覆盖。
- 审批仅测试拒绝路径，没有确认创建测试事件，也没有修改已有记忆。测试聊天记录保留在会话 44。
