# 记忆浏览器缺陷修复验收 · 2026-10-23

本轮修复浏览器报告中的 3 项缺陷，并处理记忆中心文本框的尺寸观察依赖。保留原有未提交改动，未提交、推送或部署；没有清理历史数据。

## 修改结果

- **凭证漏检**：共享分类器覆盖中文带引号值、带引号字段，以及正文/代码块中的配置。统一记忆策略拒绝这些内容，Flash、Pro 和 Spring AI 的实际出站 HTTP 测试确认副本脱敏，原文与鉴权字段保持不变；普通密码话题仍可讨论。
- **候选旧决定**：批准与拒绝共享用户锁，拒绝通过 PENDING 条件更新后才写指纹；重复拒绝不重复处理，相反终态的旧决定返回 409。新增真实事务并发测试，网页冲突后刷新并显示说明。
- **连续编辑旧 ID**：保存后重新加载当前正式记录及元数据，清除旧详情缓存。失败保留草稿；保存已成功但刷新失败时告知已保存，并暂禁旧 ID 的后续操作，刷新成功再恢复。
- **ResizeObserver**：记忆中心的正文编辑、候选确认与拒绝原因均改为原生固定行数 textarea，沿用主题变量、长文本内部滚动。候选弹框移出“存在冲突”的条件，单条无冲突候选也能操作。

契约见 [MEMORY-WRITES.md](../MEMORY-WRITES.md)。既有 API 路径、请求字段和正式编辑的空响应保持兼容，小程序调用文件没有修改。

## 修复后的浏览器复验

通过 Edge 实际操作 `http://localhost:5174/ai-memory`，只使用隔离数据库 `moodcopilot_memory_acceptance_20261022`、合成用户 990001：

3. 长文本编辑前后高度均约 88.8px，scrollHeight 从 87 增至 490，overflowY=auto；取消草稿不落库。两个新验收标签页均未记录 ResizeObserver 警告，自动隔离用例同样未产生该告警。结论限于本轮覆盖区域，不代表全站所有尺寸观察都已消除。

未清理旧测试历史或此前缺陷留下的数据。没有新增生产迁移；真实 AI 的聊天审批主流程已在前次浏览器回归完成，本轮修复后无需重复付费模型调用，出站脱敏由本地 HTTP 捕获测试验证。微信真机、全站主题与性能压测不属于本轮验收。
