# Phase 9：报告日记摘要 + 陪跑完善 + 引用栏

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 报告页日记链接显示内容摘要、陪跑加 Redis 缓存和 AI 聊天入口、聊天页加引用栏、同频推荐用摘要替代情绪标签。

**Architecture:** 后端增加陪跑缓存和引用上下文拼接；前端增加聊天引用栏组件和陪跑→聊天跳转入口；报告页情绪行下方显示内容摘要文字。

**Tech Stack:** Spring Boot + Vue 3 + Naive UI + Redis（同现有技术栈）

---

## 9.1 报告页日记显示内容摘要

**问题**：周报/月报的情绪趋势行只通过 `title` tooltip 显示日记摘要，用户必须悬停才能看到，不够直观。

**方案**：趋势行下方增加一行摘要文字（前 25 字），点击可跳转日记详情。与自定义总结卡片已有的摘要链接风格对齐。

### 后端

无改动——`WeeklyReportView.DailyMood` 已有 `contentSnippet` 字段。

### 前端

| 文件 | 变更 |
|------|------|
| `pages/ReportPage.vue` | 周报/月报情绪行下方加摘要文字；统一自定义总结的日记链接显示 |
| `stores/diary.ts` | 无改动（`DailyMood` 已有 `contentSnippet`） |

---

## 9.2 陪跑缓存

**问题**：每次访问广场都实时调 AI 生成陪跑建议，响应慢且浪费 token。

**方案**：陪跑结果写入 Redis，TTL 15min。用户写新日记时清除缓存。

### 后端

| 文件 | 变更 |
|------|------|
| `diary/DiaryService.java` | `coachingPlan()` 加 Redis 缓存读写；`evictUserCache()` 加 `coaching:{userId}` 清除 |

缓存 key：`coaching:{userId}`，TTL 15min。

---

## 9.3 同频推荐改进

**问题**：同频推荐直接显示原始情绪标签（「焦虑」「烦躁」），过于刻意，与温暖陪伴的定位不符。

**方案**：用匹配日记的内容摘要（前 30 字）替代情绪标签；匹配逻辑优先返回今天发布且情绪相同的公开日记。

### 前端

| 文件 | 变更 |
|------|------|
| `pages/SquarePage.vue` | 同频推荐区域显示内容摘要而非情绪标签；增加引导文字「有人和你感同身受」 |

后端 `todayMatch()` 逻辑已有，仅调整前端显示。

---

## 9.4 陪跑 → AI 聊天入口

**问题**：陪跑给了建议，但用户想深入聊时没有入口。

**方案**：陪跑文字下方加「和 AI 聊聊这个话题」按钮。点击跳转聊天页，自动新建/进入对话，陪跑建议和最近 3 篇日记自动带入引用栏。

### 后端

| 文件 | 变更 |
|------|------|
| `ai/ChatService.java` | `chat()` 方法签名加 `String references` 参数；引用内容拼入 system prompt |
| `ai/ChatController.java` | `POST /conversations/{id}` SSE 接口 body 加 `references` 字段 |

注意：引用栏的引用内容由前端在 SSE 请求 body 中传过来，后端不做持久化存储（仅该次对话 prompt 使用）。

### 前端

| 文件 | 变更 |
|------|------|
| `pages/SquarePage.vue` | 陪跑面板加「和 AI 聊聊这个话题」按钮；点击时通过 router state 传递 coaching 文字 + 最近 3 篇日记摘要 |
| `pages/ChatPage.vue` | 聊天输入框上方加引用栏组件；接收 router state 自动添加引用；`send()` 时将引用内容拼入请求 body |
| `components/ReferenceBar.vue` | **新建** — 引用栏组件（可移除卡片 + 添加日记引用按钮） |

### 引用栏设计

```
┌─────────────────────────────────────────┐
│ [陪跑建议] ×  [今天日记] ×  [+ 引用日记] │  ← 引用栏
├─────────────────────────────────────────┤
│ (聊天消息区)                              │
├─────────────────────────────────────────┤
│ (输入框)                                  │
└─────────────────────────────────────────┘
```

- 每个引用以紧凑卡片展示（灰色底、圆角、× 移除按钮）
- 「+ 引用日记」按钮弹出最近 7 篇日记列表（Popover），点选添加
- 引用内容随 `send()` 一起发给后端
